# پڕۆژەی ئەپی ئەندرۆیدی Shwan (`https://shwan.unaux.com/`)

ئەم پاکێجە پڕۆژەی تەواوی ئەپی ئەندرۆیدە بۆ وێبسایتی **https://shwan.unaux.com/** لەگەڵ سیستەمی خۆکاری گونجاندنی دیزاین لەگەڵ شاشەی مۆبایل.

---

## تایبەتمەندییەکانی ناو ئەپەکە
1. **گونجاندنی خۆکار لەگەڵ شاشەی مۆبایل (`mobile_adapter.css` و `mobile_adapter.js`)**:
   - هەموو پەڕەیەکی ناو `shwan.unaux.com` لە کاتی کردنەوەدا بە شێوەی خۆکار کۆدی ستایلی مۆبایلی بۆ زیاد دەکرێت تا هیچ نووسین و خشتە و وێنەیەک لە شاشەی مۆبایل دەرنەچێت.
2. **گونجاو لەگەڵ ڕاژەی `unaux.com`**:
   - چالاککردنی تەواوی `CookieManager` و `DOM Storage` کە پێویستە بۆ تێپەڕاندنی سیستەمی پاراستنی (`aes.js`) ڕاژەی `unaux.com`.
3. **تایبەتمەندییەکانی مۆبایل**:
   - ڕاکێشان بۆ خوارەوە بۆ نوێکردنەوەی پەڕە (Pull-to-Refresh).
   - کارکردنی دوگمەی گەڕانەوەی مۆبایل (Back Button).
   - هێڵی پیشاندانی خێرایی بارکردنی پەڕە لە سەرەوەی شاشەکە.
   - پەڕەی تایبەت بە نەبوونی ئینتەرنێت بە زمانی کوردی (`offline.html`).
   - پشتگیریکردنی بارکردن و دابەزاندنی فایل و کردنەوەی لینکەکانی واتسئەپ، تێلێگرام و پەیوەندیکردن.

---

## چۆنیەتی وەرگرتنی فایلی دامەزراندن (`.apk`) بە ٢ ڕێگە

### ڕێگەی یەکەم: بەبێ هیچ بەرنامەیەک لە ڕێگەی GitHub (ئاسانترین ڕێگە تەنانەت بە مۆبایلیش)
1. هەژمارێکی بێبەرامبەر لە ماڵپەڕی GitHub دروست بکە و Repositoryـیەکی نوێ بکەرەوە.
2. فایلەکانی ناو ئەم ZIPـە دەربهێنە (Extract) و هەموویان باربکە (Upload) بۆ ناو Repositoryـیەکەت.
3. بڕۆ سەر بەشی **Actions** لە سەرەوەی پەڕەی GitHub؛ دەبینیت خۆکارانە دەست دەکات بە دروستکردنی ئەپەکە (`Build Shwan Android APK`).
4. دوای نزیکەی ٢ بۆ ٣ خولەک، کلیک لەسەر ناوی پرۆسەکە بکە و لە خوارەوە لە بەشی **Artifacts** فایلی **`Shwan-Android-APK`** دابەزێنە کە فایلی `app-debug.apk`ـی تێدایە و ڕاستەوخۆ لەسەر مۆبایل دادەمەزرێت!

### ڕێگەی دووەم: لە ڕێگەی بەرنامەی Android Studio لەسەر کۆمپیوتەر
1. فایلی ZIPـەکە دەربهێنە (Extract).
2. بەرنامەی **Android Studio** بکەرەوە و کلیک لەسەر **Open** بکە و فۆڵدەری پڕۆژەکە هەڵبژێرە.
3. لە مێنۆی سەرەوە بڕۆ بۆ **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
4. دوای تەواوبوون، کلیک لەسەر **locate** بکە بۆ وەرگرتنی فایلی `app-debug.apk`.

## چۆنیەتی گونجاندنی خودی وێبسایتەکەشت لەسەر هەموو وێبگەڕەکانی مۆبایل (ئایفۆن و ئەندرۆید)
جگە لە ئەپەکە، ئەگەر دەتەوێت هەر کەسێک بە Safari یان Chrome لە مۆبایلەوە سەردانی `https://shwan.unaux.com/` دەکات دیزاینەکەی بە ڕێکی ببینێت:
1. فایلی `shwan_mobile_responsive.css` باربکە بۆ ناو فۆڵدەری سەرەکی وێبسایتەکەت (`htdocs` لەناو پانێڵی `unaux.com`).
2. ئەم دوو دێڕە بخەرە ناو بەشی `<head>` لە فایلی `index.html` یان `header.php`ـی وێبسایتەکەت:
```html
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<link rel="stylesheet" href="/shwan_mobile_responsive.css">
```
